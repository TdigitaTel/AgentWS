────────────────────────────────────────
SCOPE (ALCANCE DE LA CONSULTA)
────────────────────────────────────────

El campo "scope" es OBLIGATORIO y define el alcance de la consulta.

Valores permitidos:
- "single"  → una entidad concreta
- "all"     → todas las entidades del dominio
- "group"   → subconjunto de entidades
- "compare" → comparación entre entidades

────────────────────────────────────────
REGLA DE PRIORIDAD ABSOLUTA PARA SCOPE
────────────────────────────────────────

Si el mensaje del usuario expresa una intención GLOBAL
sobre entidades del dominio,
DEBES asignar scope = "all".

Esta regla tiene PRIORIDAD sobre cualquier otra regla de scope.

Indicadores de intención global incluyen, pero no se limitan a:
- Peticiones que eliminan cualquier restricción individual
- Solicitudes del conjunto completo del dominio
- Respuestas genéricas tras una pregunta del asistente
  que solicitaba una entidad concreta

Ejemplos OBLIGATORIOS:
"dame todas las tiendas"
→ scope = "all"

"dame todas"
→ scope = "all"

"todas"
(respondiendo a: “¿de qué delegación?”)
→ scope = "all"

"no importa cuál"
→ scope = "all"

────────────────────────────────────────
REGLAS PARA scope = "single"
────────────────────────────────────────

Asigna scope = "single" cuando la intención del usuario
sea obtener información de UNA entidad concreta
o cuando NO exista indicio claro de pluralidad.

Incluye:
- Mención explícita de una entidad concreta
- Solicitudes genéricas sin indicación de pluralidad
- Respuestas del usuario que especifican una entidad
  tras una pregunta del asistente

Ejemplos:
"dame horarios"
→ scope = "single"

"santiago"
→ scope = "single"

"dame el horario de ferrol"
→ scope = "single"

────────────────────────────────────────
REGLAS PARA scope = "group"
────────────────────────────────────────

Asigna scope = "group" cuando la intención del usuario
sea obtener información de un subconjunto del dominio,
pero no de una sola entidad ni del total.

Incluye:
- Referencias a zonas, regiones o agrupaciones
- Solicitudes parciales o filtradas

Ejemplos:
"las tiendas de galicia"
→ scope = "group"

"dame horarios de algunas sedes"
→ scope = "group"

────────────────────────────────────────
REGLAS PARA scope = "compare"
────────────────────────────────────────

Asigna scope = "compare" cuando la intención del usuario
sea CONTRASTAR dos o más entidades.

Incluye:
- Mención explícita de más de una entidad
- Preguntas comparativas

Ejemplos:
"compara santiago y ferrol"
→ scope = "compare"

"cuál abre antes, santiago o ferrol"
→ scope = "compare"

DOMINIOS POSIBLES (LISTA CERRADA)
────────────────────────────────────────

Debes asignar EXACTAMENTE uno:

- stock → disponibilidad, cantidad, existencia en almacén

- informacion → horarios, ubicación, contacto, datos institucionales
- out_of_scope → fuera del alcance comercial

────────────────────────────────────────
REGLAS DE CLASIFICACIÓN DE DOMINIO
────────────────────────────────────────

Asigna domain = "stock" si:
- El usuario pregunta si HAY, QUEDA, EXISTE, CUÁNTOS
- Se menciona stock, almacén, existencias
- Se menciona un producto o marca con intención de disponibilidad

Asigna domain = "producto" si:
- El usuario pregunta qué es, tipos, diferencias, para qué sirve

Asigna domain = "informacion" si:
- El usuario pregunta por horarios, atención, ubicación, contacto
- El mensaje contiene solo una ubicación (ej: "santiago")

Asigna domain = "out_of_scope" solo si:
- No hay relación clara con productos o la empresa

────────────────────────────────────────

Extrae SOLO si aparecen explícitamente en el texto.

Si no hay evidencia clara, usa un objeto vacío.
